# Training Company Management Application

A comprehensive web application for managing Torn City training companies with Discord integration.

## Project Structure

- `backend/` - Node.js API server with Express and Prisma
- `frontend/` - React client application with Vite
- `discord-bot/` - Discord bot integration
- `shared/` - Shared utilities and types
- `docs/` - Project documentation

## Development Setup

See `docs/setup.md` for detailed setup instructions.

## Technology Stack

- **Backend**: Node.js, Express.js, Prisma, SQLite/PostgreSQL
- **Frontend**: React 18, Vite, Tailwind CSS
- **Discord**: Discord.js v14
- **Deployment**: Railway.app
